개발 사항

  • 플레이어 입력 좌표를 실시간 샘플링해 템플릿과의 유사도를 점수화하는 제스처 드로잉 마법 시스템
  • 도형 간 공간 관계(Inside, Surround)와 중복 방지 규칙을 분석하는 콤보 알고리즘
  • Cost 기반 헥스 패스파인딩으로 AP 이동 범위 시각화 및 타일 미리보기
  • EditorWindow를 확장해 스킬/업그레이드 트리를 시각적으로 배치·연결하는 노드 에디터 자체 개발
  • ScriptableObject 자동 생성 및 C# 스크립트 연결 자동화 파이프라인 구축

회고

인식 정확도를 높이기 위해 샘플링 점 개수를 32개에서 64개로 늘렸고, 업그레이드 트리 관리를 위해 노드 에디터와 ScriptableObject 자동화 파이프라인을 만들어 개발 효율을 끌어올렸습니다. 개발 편의성이 개발 속도에 큰 영향을 미친다는 것을 알았습니다. 또한 AI는 전체 코드를 한 번에 요청하기보다 기능 단위로 명확한 조건을 주고 요청할 때 설계 의도에 맞는 코드가 나온다는 것을 깨달았습니다.
